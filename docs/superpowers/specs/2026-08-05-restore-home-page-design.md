# ホームデザイン復旧 設計

## 目的

PR #13 で SPA 化した際に失われた、WAN NYAN CLINIC のポップなランディングページのデザインとコンテンツを、ホームルート `/` に復旧する。モジュールページ、通常パスのルーティング、アクセシビリティ対応は維持する。

## 復旧する体験

- 肉球ブランド、カラフルな背景装飾、手描き風の枠線と影を含むヒーロー
- 予約・カルテ・待合室・通知を見せる動物病院ダッシュボード
- WAN NYAN OS の7機能、現場で増えた7件の問題、Module 00 への明確な導線
- 小画面では内容を欠落させず、一列レイアウトと横スクロール可能なタイムラインへ再配置する

## アーキテクチャ

`pages/home-page.ts` にホーム専用のセマンティックな DOM 構築を置く。既存の SPA エントリポイントとルーターは変更せず、Module 00 の導線は現在の正規 URL `/modules/00-break-the-app/` を使う。

`styles/base.css` にホーム専用のクラスを追加し、既存のモジュールページのスタイルを壊さないよう `.home-page` 配下で限定する。元の静的ページにあった外部 CDN 依存の Shiki 処理は復元しない。コード導線は静的な `pre > code` で意味と可読性を保つ。

## データとリンク

表示するコピーと擬似ダッシュボードの内容は、PR #13 の親コミットにあったホームを正とする。ページ内ナビゲーションは `#system`、`#features`、`#problems` を指し、SPA ルーターが横取りしないフラグメントリンクとする。Module 00 は正規 URLへ内部遷移する。

## テストと検証

- ホーム描画テストで、復旧した主要セクション、機能数、問題数、Module 00 の正規 URL、ページ内アンカーを検証する。
- CSS の見た目はビルド後の画面で確認し、狭い画面で横溢れや内容欠落がないことを確認する。
- docs アプリのテスト、型検査、production build を実行する。
