# 学習用セットアップ

動物病院の予約・カルテ管理システムを題材に TypeScript のコードを変更します。演習は、各 Session の「演習」ページのブラウザ内で行います。ローカルへ clone する必要はありません。

## 必要なもの

- デスクトップ版 Chrome または Edge の現行版

データベース、Docker、外部サービスのAPIキーは必要ありません。コーディングエージェントは必須ではありません。

演習のコードは、ブラウザ内の隔離環境で動きます。ローカルPCのファイルには触りません。この環境は、デスクトップ版の Chrome または Edge で動きます。

## 演習の進め方

各 Session の「演習」ページで、悪い変更の一覧を読み、Linter の規則、型のテスト、テストのどれかを足します。「検出を確かめる」を押すと、足した仕組みが悪い変更を検出するか、正しいコードを誤って検出しないかが表に出ます。

作業内容は、そのブラウザに保存されます。ページを閉じても、同じブラウザで開き直せば、続きから進められます。別のブラウザや別の PC には引き継がれません。

詰まったときは、ページの「解答の例を見る」を開きます。

## 手元でも動かしたい人向けの準備

次の作業は任意です。演習には不要です。手元で教材サイトやデモ画面を動かしたい人だけが行います。

### 必要なもの

- Node.js 20以上
- pnpm 9.12.0
- Git

ターミナルで次を実行して確認します。

```bash
node --version
pnpm --version
git --version
```

Node.js は `v20` 以上、pnpm は `9.12.0` であることを確認してください。Git はバージョン番号が表示されれば準備できています。

### リポジトリの取得

作業する場所でリポジトリを clone します。

```bash
git clone https://github.com/iwasa-kosui/fp-with-ts-hands-on.git
cd fp-with-ts-hands-on
```

### 依存関係のインストール

```bash
pnpm install --frozen-lockfile
```

### 教材サイトの表示

```bash
pnpm dev
```

ターミナルに表示された localhost のURLを Chrome または Edge で開きます。開発サーバーを終了するときは `Ctrl+C` を押します。

### S0 のデモ画面

S0 の「あとで読む」のページが、デモ画面の起動手順を案内しています。

```bash
pnpm demo:00
```

デモは `http://localhost:3000` を使います。終了するときは `Ctrl+C` を押します。画面の「デモを初期状態へ戻す」を押すと、データが初期状態へ戻ります。

## 演習後の振り返り

相互レビューのあと、[レビュー観点シート](./review-sheet.md) に、話した内容を1行ずつ書きます。書く内容は、自分が足した仕組み、検出されなかった変更は何を変えたのか、その変更を検出するには何を追加すればよいかです。S3、S4、S6 の欄には、この仕組みで検出できないことも書きます。S2 だけは、default を残したいのはどんなときかと、残すなら何で漏れを検出するかを書きます。自分の仕組みが選ばれなかった回も、班で見た仕組みを自分の仕組みに当てはめて書きます。

## うまく進まないとき

[トラブルシューティング](./troubleshooting.md)を確認してください。ハンズオンで質問する場合は、画面に出ている文言と、使っているブラウザの名前を進行役へ共有します。
