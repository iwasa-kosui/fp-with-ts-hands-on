# レビュー観点シート

印刷想定: A4・片面・参加者1人につき1枚。

各演習の相互レビューの最後に、話した内容をこのシートへ1行ずつ書きます。書く欄は、自分が足した仕組み、検出されなかった変更は何を変えたのか、その変更を検出するには何を追加すればよいかです。「この仕組みで検出できないこと」の欄は、S3、S4、S6 にあります。S2 だけは、ページの問いに沿って、default を残したいのはどんなときかと、残すなら何で漏れを検出するかを書きます。

「検出されなかった変更」は、隣の人のブラウザで、相手の仕組みに検出されないように書き換えた `R1-peer-change.ts` の変更です。「検出を確かめる」で、その行が「すり抜け」になれば、作れています。自分の仕組みが選ばれなかった回も、班で見た仕組みを自分の仕組みに当てはめて書きます。
