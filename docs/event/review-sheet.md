# レビュー観点シート

印刷想定: A4・片面・参加者1人につき1枚。

各演習で残す3成果物は「守る不変条件の1文」「依頼文」「型で守れなかった残り」です。言語化で1つ目、委譲前に2つ目、班内相互レビューの最後の1分で3つ目を書きます。自分の差分が選ばれなかった回も、班で見た差分を自分の実装へ当てはめて必ず書いてください。
