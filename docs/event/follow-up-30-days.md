# 30日後フォローアップ運用手順

対象イベント: 2026年8月30日開催

この文書は PRD-11 を実行するための送付手順、設問、集計規則を定めます。設問と送付方法は準備済みです。実送付は開催後のため未実施です。

## 担当と日程

- Accountable: 主催者。送付可否、回答フォーム、集計結果の公開範囲を承認します。
- Responsible: 運営責任者。フォーム作成、一斉連絡、リマインド、匿名集計を実行します。
- D+23（2026年9月22日）: 当日の全参加者数を確定し、下記設問で匿名フォームを作り、回答URLを発行します。
- D+27（2026年9月26日）: 主催者が設問、回答URL、送信対象、個人情報を収集しない設定を確認します。
- D+30（2026年9月29日）: 運営責任者が初回案内を送付します。
- D+34（2026年10月3日）: 同じ送付先へリマインドを1回だけ送ります。
- 回答締切 D+37（2026年10月6日）23:59 JST。D+38に集計します。

## 送付方法と回答導線

Primary は、参加募集に使ったイベント管理サービスの一斉連絡機能です。運営責任者はサービスの出席済み状態または当日参加リストを受付記録と突き合わせ、当日参加が確認された登録者だけへ対象を絞って一斉連絡します。本文へ匿名フォームの回答URLと回答締切を入れます。回答者は「一斉連絡を開く → 回答URLを開く → 4設問へ回答する → 送信完了を確認する」の順に進みます。メール本文への返信では回答を受け付けません。

イベント管理サービスで出席済みの登録者をfilterできない場合は、運営責任者が受付記録を正として、アクセス制限された作業場所で登録情報から当日参加者だけを抽出します。主催者の公式メールアカウントから、その連絡先だけを BCC にして匿名フォームの回答URLを送ります。抽出したPIIはこのリポジトリへ置かず、D+34のリマインド送付後24時間以内、遅くともD+35までに作業場所から削除します。イベント管理サービスまたは主催者が法令・規約に従って保有する元の登録情報まで、この手順で削除するものではありません。

フォーム機能が匿名回答に対応しない場合は、ログイン不要・メールアドレス収集なしに設定した主催者管理のフォームを fallback とします。登録者名簿はイベント管理サービスまたは主催者のアクセス制限された保管場所だけで扱い、このリポジトリへ複製しません。

送付母集団を作る名簿と成功指標の分母は、どちらも受付で確定した当日の全参加者です。欠席登録者は送付対象にも回答対象にも含めず、成功指標の分子へ加えません。連絡への同意や利用可能な連絡経路がなく送付できない当日参加者は、送付不能として記録したうえで分母には残します。

参加時の同意範囲に開催後連絡が含まれない、または利用可能な連絡経路がない参加者へは送付しません。送付不能数を記録し、都合のよい別経路を推測して連絡しません。

## 設問

PRD の「30日後」計測計画を弱めず、次の4項目をそのままフォーム契約にします。

### 1. 実践した行動

実践した行動の種類を選択式で確認する

該当するものをすべて選択してください。

- 既存実装の調査
- 改善提案
- テスト追加
- 局所的な実装変更
- レビューでの指摘
- 実践していない
- その他

### 2. 対象・手段・判断・効果

対象となった問題、選んだ手段、判断理由、確認した効果を自由記述で確認する

会社名、顧客名、リポジトリ名、URL、ソースコード、個人名を含めず、抽象化して記入してください。未確認の効果は「未確認」と書けます。

### 3. 実践できなかった障壁

実践できなかった場合は、知識、適用対象、時間、チーム合意、技術的制約のどこが障壁だったかを確認する

「実践していない」を選んだ場合に、該当する障壁を複数選択し、必要なら機密情報を含まない補足を任意で記入してください。

### 4. 次に試す行動

次に試す行動が決まっているかを確認する

「決まっている / まだ決まっていない」を選び、決まっている場合だけ次の小さな行動を任意で記入してください。

## 匿名性、集計、未回答の扱い

- フォームでは氏名、メールアドレス、会社名、所属、ソースコードを収集しません。イベント管理サービスが送付のために持つ連絡先と、匿名フォームの回答を結合しません。
- 自由記述に PII や機密情報が含まれていた場合は集計対象から除外し、原文をこのリポジトリへ転載しません。
- 回答率の分母は当日の全参加者です。未回答者は「実践していない」と断定せず「実践を確認できなかった」として成功指標の分子へ加えません。回答率、送付不能数、各指標の全参加者比を併記します。
- リポジトリへ残せるのは匿名の集計値だけです。回答原文、回答URL、参加者名簿、メールアドレス、その他の PII は置きません。
- 生回答は主催者と運営責任者だけがアクセスできる保管場所で集計し、集計確定から90日以内に削除します。
