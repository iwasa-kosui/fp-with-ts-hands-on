<p>課題4は、直した状態を次の変更から守ることです。別の人が <code>new Date()</code> を戻しても、型検査は通ります。ここで扱う変更はどれも型検査を通るため、仕組みは Linter のルールとテストの2つです。演習で実装するのは検出の仕組みで、保存する側の実装は参照するだけです。</p>

<p>変更を選んで結果を比較してください。時刻や ID を直接生成する変更は Linter のルールとテストの両方が、store を2回呼ぶ変更と clock を再取得する変更はテストだけが検出します。</p>

<p>Linter のルールは <code>no-restricted-syntax</code> です。<code>selector</code> の <code>[…]</code> には、検出する範囲を絞る条件を記述します。</p>

}, {
  selector: "NewExpression[callee.name='Date'][…]",

}]`}
