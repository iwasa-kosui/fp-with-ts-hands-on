      <p>カメの診察を開始すると、予約の状態は「診察中」に変わりました。</p>
      <p>ところが、監査記録はどこにも残りませんでした。</p>

    <p><strong>課題1</strong>: 予約の状態だけが残りました。監査記録がないので、誰がいつ診察を始めたかを後から調べられません。ゴールは、状態と監査記録を、両方残すか、どちらも残さないかのどちらかにすることです。</p>
    <p><strong>課題2</strong>: 時刻と ID を固定できません。同じ入力でも出力のイベントが変わるので、テストの結果が時刻で変わります。ゴールは、時刻と ID を外から渡して、テストの結果を毎回同じにすることです。</p>
    <p><strong>課題3</strong>: 保存の失敗と競合を、呼び出し側へ返し分けられません。開始のコードは、競合（別の依頼が先に診察を始めていたこと）を <code>Err</code> で返せません。開始のコードは、保存の時点で予約の今の状態を確かめずに書き込みます。困るのは、後から届いた依頼が先の結果を上書きし、結果は <code>Ok</code> のままなので、画面に失敗の案内が出ないことです。ゴールは、保存の失敗と競合を、呼び出し側へ返し分けることです。</p>
