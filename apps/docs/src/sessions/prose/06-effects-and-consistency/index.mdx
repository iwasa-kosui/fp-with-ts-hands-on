<p>獣医師が「診察を開始する」を押すと、システムは2つのことを記録します。予約の状態を「診察中」に変えることと、誰がいつ診察を始めたかを監査記録に残すことです。S05 で、片方だけ残ると困る例を読みました。</p>

<TwoRecordsFlow />

<p>この Session のゴールは、次の3つです。</p>

<ol>
  <li>状態と監査記録を、両方残すか、どちらも残さないかのどちらかにします（課題1）。</li>
  <li>時刻と ID を外から渡して、テストの結果を毎回同じにします（課題2）。</li>
  <li>保存の失敗と競合を、呼び出し側へ返し分けます（課題3）。</li>
</ol>

<p>演習では、直した状態を次の変更から守る仕組みを足します（課題4）。保存する側の実装は、読むだけです。</p>
