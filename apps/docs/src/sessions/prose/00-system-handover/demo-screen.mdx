<p>ここまでの操作と値を、手元のデモ画面で確かめます。デモ画面はデータベースに接続して動きます。</p>

<ol>
  <li>ターミナルで <code>pnpm demo:00</code> を実行します。</li>
  <li>ブラウザで <code>http://localhost:3000</code> を開きます。</li>
  <li>予約を「受付する」「診察を開始する」「診察結果を記録する」「会計を記録する」の順に操作します。</li>
  <li>会計済みの予約で「診察を開始する」を押すと、予約が診察中へ戻ります。画面の「事故再現」でも、想定外の状態や ID の取り違えを順に試せます。</li>
  <li>画面の「現在の予約内容」「予約の変更履歴」「不整合の警告」を見比べます。画面の「予約の変更履歴」が、この教材の監査記録です。</li>
  <li>「デモを初期状態へ戻す」を押すと、データは初期状態へ戻ります。サーバーを起動し直しただけでは戻りません。</li>
</ol>

<p>デモ画面は、すべての Session で同じ <code>http://localhost:3000</code> を使います。一度に1つだけ起動してください。</p>

<p>このシステムで使っている道具です。Hono は、HTTP のリクエストを処理する Web フレームワークです。SQLite は、このシステムのデータベースです。better-sqlite3 で接続し、Drizzle ORM で SQL を組み立てます。リポジトリ（Repository）は、データベースの読み書きをまとめたオブジェクトです。モックで見た <code>repository.find</code>、<code>repository.save</code>、<code>repository.appendAudit</code> は、このオブジェクトの関数です。</p>
