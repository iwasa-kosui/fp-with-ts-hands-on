<p><code>assertNever</code> を書いても、あとから誰かが <code>default</code> を「不明」を返す形に戻すかもしれません。そうした変更を悪い変更と呼びます。正しいコードを検出してしまうことを誤検知と呼びます。</p>

<p>候補は、union の <code>switch</code> と引数の型を見るもの（Linter の規則と型のテスト）と、値を渡して表示名を見るもの（テスト）です。</p>

<p><code>string</code> を受け取る <code>switch</code> は候補が0個にならないので、規則も <code>assertNever</code> も働きません。この <code>default</code> は正しいコードなので、誤検知にしてはいけません。漏れは値を渡すテストで確かめます。</p>
