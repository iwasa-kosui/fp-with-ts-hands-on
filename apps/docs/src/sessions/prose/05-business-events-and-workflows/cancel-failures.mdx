<p>失敗した工程より後の工程は実行されず、失敗の値は失敗のレールを終点まで進みます。失敗する箇所は、工程では3か所、コードでは5か所です。実行者の確認は <code>ensureUserFound</code> と <code>ensureCanManageClinic</code>、予約の確認は <code>ensureAppointmentFound</code> と <code>ensureCancellable</code>、記録して返すは <code>store</code> の競合で失敗します。競合は業務の失敗であるため Err、接続断は障害であるため例外のままで、競合の経路は図に含みません。</p>

      <p>問い: 会計済みの予約（<code>kind: "Paid"</code>）が工程へ入ると、どの工程で失敗しますか。後ろの成功の処理は実行されますか。</p>

    </li>

    </li>
