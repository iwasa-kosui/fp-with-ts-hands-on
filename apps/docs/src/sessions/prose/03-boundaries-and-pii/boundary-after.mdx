<p><code>StartExaminationInput.parse</code> は、<code>schemaResult</code> が、<code>z.object</code> と印の付いた <code>AppointmentId</code>・<code>VeterinarianId</code> の schema から作った関数です。</p>

<p><strong>解けたこと</strong>: 課題1が解けました。検査を通った値だけが、型の付いた値として内側へ入ります。検査に失敗した値は内側へ入らず、今はサーバーが失敗を返す HTTP の状態（500）になります。失敗の扱いは S04 で変えます。</p>

<p><strong>解けないこと</strong>: 形式の検査は、実在を確かめません。たとえば、獣医師の欄に予約のIDが届いても、UUID の形が正しければ通ります。Branded Type が防ぐのは、検査していない <code>string</code> や別の ID を、ID の型の引数へ渡す変更です。</p>
