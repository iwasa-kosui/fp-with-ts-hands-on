<p>課題1の2点目、route が文言で判別する点は、失敗の種類（<code>kind</code>）で分岐することで解決します。useCase が <code>kind</code> を持つ失敗を Result で返すため、route は文言を検証せずに、<code>kind</code> ごとに画面のお知らせを定義できます。<code>match</code> は、Ok のときの処理と Err のときの処理を1か所にまとめて渡し、Result を画面の応答に変換する関数です。</p>

<p>予約が見つからない失敗には「予約が見つかりません」を、状態不正には「現在の予約状態ではこの操作を実行できません」を表示します。獣医師は、前者の文を読んで予約を探し直し、後者の文を読んで予約の現在の状態を確認します。ここまでで、失敗の種類ごとに別々のお知らせを表示できます。</p>
