<p>Result は、成功か失敗かを値として表す型です。S03 の Result と、neverthrow（Result 型を提供するライブラリ）の Result は、別の型です。S03 の Result（<code>domain/shared/schemaResult.ts</code> で定義）では、Err が値を持ちません。neverthrow の Err は、失敗の理由の値を持てます。S04 の useCase は neverthrow の Result を返し、route の入力の検査は S03 の Result のままです。</p>

<p>neverthrow の Result は <code>Result&lt;成功の型, 失敗の型&gt;</code> と表記します。成功は <code>ok(値)</code> が返す Ok、失敗は <code>err(値)</code> が返す Err です。修正前は、戻り値の型 <code>Appointment</code> から失敗を読み取れませんでした。修正後は、戻り値の型に失敗が現れます。<code>AppointmentNotFound</code> の定義は次のページで確認します。</p>
