<p>業務イベントごとに予約の状態を変える関数を、この回では<strong>遷移関数</strong>と呼びます。この回の開始コード（<code>examples/session-01</code>）は、状態の名前を格納する項目 <code>kind</code> で 6 つの状態を分け、状態ごとの遷移関数を持ちます。</p>

<p>事故は S00 の配布コードの <code>updateStatus</code> で発生しました。この回の開始コードは、実行時に <code>requireKind</code> で例外（処理を中断してエラーを知らせる仕組み）を投げます。ただし、誤りを検出できるのは実行したときだけです。<code>startExamination</code> の引数の型が <code>Appointment</code> であり、どの状態の予約も受け取るためです。この回の目的は、誤った状態の予約を渡す呼び出しを、実行したときではなく、型検査のときに検出することです。ゴールは、遷移関数の引数を、受け取れる状態の型に絞ることです。</p>
