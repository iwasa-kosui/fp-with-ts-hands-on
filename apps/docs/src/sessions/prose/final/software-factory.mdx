<p>StrongDM の Justin McCarthy は、2026年2月6日の<a href="https://factory.strongdm.ai/">記事</a>で、Software Factory を「仕様とシナリオが Agent を動かす非対話型の開発」と説明しました。この開発では、Agent がコードを書き、検証用のハーネス（テストを動かして結果を集める仕組み）を実行し、人のレビューなしに結果を収束させます。同じ記事は、シナリオをコードベースの外に置くことが多いと書いています。この語は文脈によって別の意味でも使われるので、ここではこの記事の用法だけを扱います。</p>

<p>この教材の演習テストは、この記事のシナリオに近い役割を持ちます。ただし、記事のシナリオは、画面の操作から保存までを通して確かめる end-to-end のユーザーストーリーで、LLM が検証します。演習テストは型検査と単体テストなので、確かめる範囲が狭くなります。また、演習テストは配布コードと同じリポジトリにあるので、Agent が書き換えられます。そのため、参加者は差分を確かめます。この教材は人のレビューをなくしません。型検査とテストで確かめられない点は、相互レビューで確かめます。</p>
