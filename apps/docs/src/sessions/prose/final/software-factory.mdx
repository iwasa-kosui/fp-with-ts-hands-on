<p>StrongDM の Justin McCarthy は、2026年2月6日の<a href="https://factory.strongdm.ai/">記事</a>で、Software Factory を「仕様とシナリオが Agent を動かす非対話型の開発」と説明しました。この開発では、Agent がコードを実装し、検証用のハーネス（テストを実行して結果を集計する仕組み）で検証し、人のレビューなしに結果を収束させます。同じ記事は、シナリオをコードベースの外に配置することが多いと記載しています。この語は文脈によって別の意味でも使われるため、ここではこの記事の用法だけを扱います。</p>

<p>この教材の演習テストは、この記事のシナリオに近い役割を担います。ただし、記事のシナリオは、利用者の一連の操作を端から端まで検証する end-to-end のユーザーストーリーで、LLM が検証します。演習テストは型検査と単体テストであるため、検証する範囲が狭くなります。また、演習テストは配布コードと同じリポジトリにあるため、Agent が書き換えられます。そのため、参加者は差分を確認します。この教材は人のレビューをなくしません。型検査とテストで検証できない点は、相互レビューで確認します。</p>
