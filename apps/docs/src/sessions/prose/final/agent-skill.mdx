<p>ローカル環境で AI を使う人向けのページです。スキルは、AI が最初から正しい方向でコードを実装するように指示する文書です。指示が守られなかった場合に検出するのは、各回で追加した仕組みです。</p>

<ol>
  <li>各回で追加した Linter のルールとテストの名前を記載します。</li>
  <li>変更の前に読む内容として、守る形を短く記載します。「時刻と ID は port から受け取る」「失敗は <code>Err</code> で返す」のように記載します。</li>
  <li>変更の後に実行する内容として、型検査、Linter、テストのコマンドを記載します。</li>
  <li>検査が失敗した場合は、ルールを緩和せずに原因を報告するように記載します。</li>
</ol>

<p>スキルに記載するだけでは、誤りを検出できません。同じ検査を CI でも実行します。</p>
