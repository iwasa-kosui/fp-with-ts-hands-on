<p>手元で AI を使う人向けのページです。スキルは、AI に最初から正しい方向で書かせるための文書です。守られなかったときに検出するのは、各回で足した仕組みです。</p>

<ol>
  <li>各回で足した規則とテストの名前を書き出します。</li>
  <li>変更の前に読むこととして、守る形を短く書きます。時刻と ID は port から受け取る、失敗は <code>Err</code> で返す、のように書きます。</li>
  <li>変更の後に実行することとして、型検査、Linter、テストのコマンドを書きます。</li>
  <li>検査が失敗したら、規則を緩めずに原因を報告するように書きます。</li>
</ol>

<p>スキルに書くだけでは検出になりません。同じ検査を CI でも動かします。</p>
