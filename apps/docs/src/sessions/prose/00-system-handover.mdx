  <h2>画面操作の結果がデータベースにどう残るか</h2>
  <p>{"\n"}画面で操作すると、現在の予約内容と、各操作を行った後の変更履歴が SQLite に保存されます。{"\n      "}サーバーを起動し直しても両方のデータは残り、{"\n      "}「デモを初期状態へ戻す」を実行したときだけ初期状態へ戻ります。ここでも修正はせず、事故報告と現在の動きがどこで結び付くかを確認します。{"\n"}</p>
