# Session 01: ビジネスイベントとワークフロー

S1 はコード演習ではありません。動物病院の一日を描いた散文からドメインイベントを拾い、コマンドとアクターを添えて、集約を班で見つけます。進行は、ブリーフィング3分、説明4分、班ワーク6分、レビュー2分の `3+4+6+2=15分` です。

実装は Session 02 から始めます。S1 には参加者向け実行コマンドを設けません。

## 扱う語彙

- **ドメインイベント**: 業務上起きた出来事。過去形で書きます
- **コマンド**: 誰かが出した依頼。ドメインイベントを引き起こします
- **ワークフロー**: 一つの依頼を受けてドメインイベントを出すまでのひとかたまり
- **集約**: コマンドを受けて状態を変え、ドメインイベントを出す単位。一貫性を保って一緒に変わるまとまりです

ポリシー、読み取りモデル、外部システムは扱いません。型名も S1 では出しません。

## 手順4段

1. 起きた出来事を過去形で書き出す
2. 時間の順に並べる
3. それぞれの出来事が、誰の何の依頼で起きたかを添える
4. 同じ集約を変えるドメインイベントをまとめ、集約に名前を付ける

## 班ワークの場

班ワークはページ上ではなく Excalidraw で行います。TA がテンプレートを開き、Live collaboration を開始して班へリンクを配ります。

説明4分では、講師が散文からドメインイベントを1件だけ拾って Excalidraw に置いて見せます。班ワーク6分では、残りのドメインイベントを散文から拾って時系列に並べ、各イベントに誰の何の依頼で起きたかを添え、同じ集約を変えるイベントをまとめて集約に名前を付けます。

レビューでは講師回答例と比べ、粒度の違いを一つ挙げます。ここではコードを書かず、見つけた集約が S2 以降で扱う対象へつながることがゴールです。
