# Session 01: ワークフロー・カード

S1 はコード演習ではありません。診察開始を一つの業務ワークフローとして捉え、15分の班ワークでカードに整理します。進行は、ブリーフィング3分、欄の説明4分、カード作成6分、レビュー2分の `3+4+6+2=15分` です。

実装は Session 02 から始めます。S1 には参加者向け実行コマンドを設けません。
